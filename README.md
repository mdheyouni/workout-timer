# Workout Timer

An interval timer for workouts: a ready countdown, exercise and rest phases, and exercise and set counters.
You choose whether to rest between exercises, between sets, or both.

It runs in any browser, adapts to phone, tablet and desktop screens,
and can be installed on a phone's home screen. Once installed, it works offline.

All of it is one HTML file with no dependencies, plus a manifest, a service worker and icons.
